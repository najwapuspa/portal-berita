## Cara Mengambil Screenshot

1. Buka browser Chrome/Edge
2. Tekan **F12** untuk DevTools
3. Klik ikon HP/tablet untuk toggle device mode
4. Pilih ukuran yang diinginkan
5. Tekan **Ctrl+Shift+P** → ketik "screenshot" → pilih "Capture full size screenshot"
6. Simpan dengan nama sesuai tabel di atas

## Screenshot Mobile

Untuk tampilan HP:
1. Di DevTools, pilih device "iPhone 12 Pro" atau "Galaxy S8+"
2. Ambil screenshot halaman yang dibutuhkan
3. Simpan sebagai `14-mobile-*.png`
